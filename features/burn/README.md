# burn · 烧掉

把任意一个元素从中心烧掉。用在：离开场景时烧掉册页；以后第一页 → 目录也用它。

**文件：** `burn.js`（入口）· `fire-gl.js`（WebGL2 真实火）· `burn-canvas.js`（没有 WebGL2 时的备用版）· `burn.css` · `README.md`

## 用法

```js
import { burnAway } from './features/burn/burn.js';
await burnAway(el, { pad: 12, duration: 1700 });   // 纸烧光时 resolve
```

## 画面（WebGL 版）

| 层 | 做法 |
| --- | --- |
| 洞 | 元素每帧用 `clip-path: path(evenodd, …)` 挖掉；网页文字不受影响 |
| 焦痕 | 着色器按「到烧穿边界的距离」上色：浅褐 → 焦黑，边上一闪一闪的暗红余烬 |
| 火苗 | 多层噪声往上流动，套一条深色火焰色带：暗红 → 深红 → 赭橙 → 琥珀 |
| 烟 | 火苗上方的低频噪声，接近桌面的暗色 |
| 火星 | GPU 点精灵，最多 4000 颗，叠加混合，受旋转气流左右飘 |
| 热浪 | 元素上挂 SVG 位移滤镜，强度随火势变化 |

烧穿边界的形状在 JS 和着色器里用同一个公式，所以挖洞和火苗严丝合缝。

## 边界

整段约 1.7 秒烧完，火星和烟再飘 0.65 秒；画布清晰度上限 1.5 倍，结束后立即移除。系统要求减少动效时直接淡出。
