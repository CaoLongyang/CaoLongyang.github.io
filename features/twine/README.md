# twine · 丝绳

绕在卷上的两道丝绳，右侧打结，火漆挂在绳头上。展开时滑落淡出，收卷时等纸卷回去再落回来。

**单独看：** 起本地服务器后打开 `features/twine/demo.html`，或从 `lab/index.html` 进入。

**文件：** `twine.css` · `twine.js` · `demo.html` · `README.md`

## 用法

```html
<sc-twine></sc-twine>   <!-- 放在 .tilt 里 -->
```

## 事件

| 听 | 发 |
| --- | --- |
| 无（读 `body.opened` / `body.closing`） | 无 |

## 可调

`--cord-y`（绳子在卷上的高度）
