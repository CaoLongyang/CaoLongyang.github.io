# intro-controls · 跳过与重看

右下角「跳过」（开场前）/「重看开场」（展开后），左下角落款。

**单独看：** 起本地服务器后打开 `features/intro-controls/demo.html`，或从 `lab/index.html` 进入。

**文件：** `intro-controls.css` · `intro-controls.js` · `demo.html` · `README.md`

## 用法

```html
<sc-intro-controls name="Calvin" tag="handscroll · mmxxvi"></sc-intro-controls>
```

## 事件

| 听 | 发 |
| --- | --- |
| 无 | `intro:skip` · `intro:replay` |

## 可调

`--chrome` `--chrome-hi` `--chrome-line`
