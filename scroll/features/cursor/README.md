# cursor · 墨点光标

指针进入纸面时变成墨点，后面拖一团淡影；停在链接、按钮上洇开成朱色。

**单独看：** 起本地服务器后打开 `features/cursor/demo.html`，或从 `lab/index.html` 进入。

**文件：** `cursor.css` · `cursor.js` · `demo.html` · `README.md`

## 用法

```html
<sc-ink-cursor></sc-ink-cursor>
```

## 事件

| 听 | 发 |
| --- | --- |
| 无 | 无 |

## 可调

无

## 备注

触屏、减少动效时整个功能不启用；离开纸面就是系统光标。
