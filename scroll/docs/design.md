# 羊皮卷个人站 · 设计方案

> 版本 v0.1 · 2026-11-11  
> 状态：概念待确认，未开始编码

---

## 一、一句话概念

**网站不是"打开"的，是"展开"的。**

访客到达时看到的是一卷合着的羊皮卷，卷边用火漆封着。点开火漆，卷轴在 2 秒内展开，纸面从卷曲变平，露出里面的字。此后每一次翻页，都是"翻过一页纸"，而不是"加载一个新页面"。

关键词：**仪式感 · 材质 · 慢**。

---

## 二、这个想法为什么成立

大部分个人站的第一屏是"信息"——名字、一句话、几个链接。你的第一屏是"一个物件"。

这在设计上叫 **object-first entry**（物件优先的入口）。它做对了两件事：

1. **它给访客一个动作。** 人面对一个可以操作的东西，会本能地想碰一下。而面对一段文字，只会扫一眼然后决定要不要往下滚。
2. **它制造了时间差。** 从"到达"到"看到内容"之间隔了 2 秒。这 2 秒不是浪费，是定价——它暗示"里面的东西值得等"。

这也正是游戏开场做的事。**游戏感的来源不是 3D，是节奏。**

---

## 三、我必须先说清楚的三件事

这三条不是劝退，是让你在知情的前提下决定。

### 1. 开场动画是第二次访问的敌人

第一次：惊艳。第二次：想跳过。第五次：烦。

**所以必须内置三个开关：**

- 用 `localStorage` 记住"已看过"，老访客直接进入展开后的状态（0.3 秒淡入，不重播）
- 右下角常驻一个「跳过」，任何时候可点
- 首页底部留一个「重看开场」的小链接，想再看的人找得到

没有这三条，这个设计会从"炫技"变成"折磨"。

### 2. 真正的"卷曲"需要 WebGL，CSS 只能模拟

| 方案                     | 观感                | 性能    | 实现难度 |
| ---------------------- | ----------------- | ----- | ---- |
| CSS `clip-path` + 多层阴影 | 7 分（像纸被拉开，但纸面是平的） | 极好    | 低    |
| Canvas 2D 分段绘制         | 8.5 分（纸面有弧度的明暗）   | 好     | 中    |
| Three.js 真曲面 shader    | 10 分（真的一卷纸）       | 移动端危险 | 高    |

**我的建议：Canvas 2D 分段绘制。** 把纸横向切成 60 条，每条按卷曲角度做纵向缩放 + 明暗变化。观感接近满分，体积只有 8KB 左右，手机上也能 60fps。真 3D 留到以后有余力再说。

### 3. 首屏会变慢，这是硬代价

开场动画会推迟"内容可见"的时间，直接影响 LCP（最大内容绘制）和搜索引擎判断。解决办法是让开场层用纯 CSS/内联 SVG 实现、不依赖任何外部资源，保证它在 200ms 内就能画出来。**不能出现"白屏 1 秒然后才看到卷轴"**——那比没有开场更糟。

## 四、三幕结构

```
第一幕 · 封面          第二幕 · 展开           第三幕 · 书页
┌──────────┐          ┌──────────┐          ┌──────────┐
│ 一卷合着的 │  点火漆  │ 纸面从卷曲 │  展开完成 │ 首页正文  │
│ 羊皮卷     │ ──────▶ │ 变平，字浮现│ ──────▶ │ 可滚动    │
│ 火漆封印   │  2.0s   │ 逐行显影   │          │ 书签导航  │
└──────────┘          └──────────┘          └──────────┘
   等待点击              不可跳过               永久停留
```

**第一幕（等待）** — 一卷纸，中间一道火漆印。光标进入时火漆微微发亮。停留时间由访客决定，不催。

**第二幕（展开）** — 2 秒。卷轴从中间向两侧退开，纸面弧度逐渐变平，纸上的字从模糊到清晰（像墨迹渗开）。这一段不可跳过，但可加速（点击任意处 → 1.2 倍速）。

**第三幕（阅读）** — 展开后的纸就是首页。此后所有页面切换都是"翻页"：整张纸向右滑出，下一张从左侧滑入，带一点纸张的惯性回弹。

## 五、开场交互：三个方案，我推荐第三个

### 方案 A · 滚动展开

进入页面时卷着，往下滚就展开。**优点**：最可靠，移动端手势自然，无学习成本。**缺点**：没有仪式感，跟普通滚动差不太多，浪费了这个概念。

### 方案 B · 拖拽拉开

像真的拉卷轴，按住边缘往两边拖。**优点**：最有游戏感，物理反馈真实。**缺点**：访客不知道要拖多远，容易只拖一半就松手；移动端和浏览器下拉刷新冲突。

### 方案 C · 点燃火漆（推荐）

卷轴中间有一枚火漆印。点一下 → 蜡裂开、碎成几块掉落 → 纸自己展开。

**为什么推荐它**：它把"操作"压缩成一个动作（点一下），把"期待"全部交给动画。访客不需要学习任何规则，但会得到完整的仪式感。这正是游戏开场的做法——**操作极简，反馈极重**。

可选加一层：鼠标悬停火漆 1.5 秒不点，火漆会自己微微裂开一道缝（暗示"可以点"）。这是给犹豫的人的提示。

## 六、西式卷轴，还是中式手卷？

这两个是完全不同的东西，**必须先定，因为它决定整个视觉系统**。

|     | 西式卷轴（Scroll）  | 中式手卷（Handscroll）         |
| --- | ------------- | ------------------------ |
| 形态  | 上下两端有木轴，纸竖向卷起 | 横向长卷，从右往左展开，两端有"引首"和"拖尾" |
| 气质  | 奇幻、中世纪、地图、羊皮纸 | 文人、书画、题跋、印章              |
| 配色  | 深棕、暗金、烛光      | 宣纸米白、墨色、朱红               |
| 字体  | 衬线体、哥特体点缀     | 宋体、楷体、竖排                 |
| 独特性 | 中等（游戏里常见）     | **高（几乎没有网站这么做）**         |

**你之前说喜欢"温暖书卷"，那中式手卷更对。** 而且它在 AI 生成的设计里几乎不存在——这是一个天然的差异化。

但如果你想要的是"奇幻冒险"那种感觉，西式卷轴更直接。

**我的建议：中式手卷 + 一点西式的火漆仪式感。** 纸是宣纸，字是竖排，但封印用火漆而不是印章，因为火漆有"破坏"的动作，印章没有。

## 七、材质与排版规范

### 颜色（只有四个）

| 用途 | 色值                    | 说明                  |
| -- | --------------------- | ------------------- |
| 纸  | `#e9dcc0` → `#dccba6` | 唯一允许用渐变的地方，因为纸本身有光影 |
| 墨  | `#241c14`             | 不是纯黑，是偏褐的墨色         |
| 朱  | `#a83a1c`             | 印章、火漆、批注、强调         |
| 灰  | `#8a7c66`             | 次要信息、日期、编号          |

### 字体

- **正文**：思源宋体 / 霞鹜文楷（子集化，只打包实际用到的字，否则中文全字集会到 5MB）
- **装饰**：等宽字体做编号、日期、坐标
- **禁用**：无衬线黑体（会立刻破坏材质感）

### 排版规则

- 竖排右起（`writing-mode: vertical-rl`），从右往左读
- 界栏：竖线分隔，像古籍的乌丝栏
- 字号阶梯 1.25 倍，正文 17px 起
- 行距 1.9（竖排时是"列距"）
- 段落不空行，首行缩进两字

### 装饰元素

- **鱼尾**：版心中央的鱼形标记，古籍装订痕迹
- **书口**：卷边的细密横线
- **朱印**：页脚一枚方印，hover 显示"某某藏书"
- **界栏**：每列之间的细竖线

## 八、小巧思系统

### 三条原则

1. **不打扰主线** — 不点它也能读完整个站
2. **有反馈** — 碰了就有反应，哪怕只是一片叶子动了一下
3. **有隐藏感** — 不是一眼看全的，发现了会开心

### 清单

| #  | 小巧思      | 交互              | 反馈                          |
| -- | -------- | --------------- | --------------------------- |
| 1  | **盆栽**   | 鼠标靠近叶子轻微摆动；点击浇水 | 浇水后长出一片新叶；连续访问天数累计，植物慢慢长大   |
| 2  | **火漆印**  | 悬停 1.5 秒        | 微微发烫、裂开一道缝                  |
| 3  | **墨点**   | 点击纸面空白处         | 留下一个极淡的墨点，3 秒后晕开消失          |
| 4  | **文字选中** | 选中任何文字          | 高亮是朱红半透明，像朱笔批注，不是浏览器默认蓝     |
| 5  | **夜间**   | 22:00–06:00 访问  | 纸色偏暖偏暗，右下角多一盏小灯，有微弱呼吸       |
| 6  | **光标**   | 进入纸面区域          | 变成一个极小的墨点，移动时留 0.1 秒的淡影     |
| 7  | **卷边**   | 滚动到顶部/底部        | 卷轴轻轻回弹一下，有"到头了"的物理感         |
| 8  | **书签**   | 右侧垂下三根布带        | 悬停时布带轻微摆动，点击跳转              |
| 9  | **朱印**   | 页脚印章 hover      | 浮起 1px，出现"沈迟藏书"四字           |
| 10 | **彩蛋**   | 在首页输入 `烧`       | 羊皮卷右下角烧掉一小块，露出焦边（一次性，看完即恢复） |

**关于盆栽，值得单独说：** 它是唯一一个"跨会话"的小巧思——用 `localStorage` 记住访问天数，第 7 天、第 30 天植物会明显变化。这会让人产生"回来看一眼"的动机，比任何"欢迎回来"的文案都有效。但要注意：**不能变成签到打卡**，那会变成负担。它应该安静地长，不提醒、不催促。

## 九、技术方案

| 部分   | 方案                       | 说明                       |
| ---- | ------------------------ | ------------------------ |
| 展开动画 | Canvas 2D 分段绘制           | 60 条横带，每条独立缩放 + 明暗，约 8KB |
| 纸纹   | SVG `feTurbulence` 生成噪点  | 无图片请求，可调种子               |
| 字体   | 思源宋体子集化                  | 按实际用字生成，目标 < 300KB       |
| 页面切换 | View Transitions API     | 原生跨页动画，元素可变形             |
| 状态记忆 | `localStorage`           | 已看过开场、盆栽天数               |
| 降级   | `prefers-reduced-motion` | 直接跳过开场，静态呈现              |

### 性能预算

- 首屏可交互 < 1.5s
- 开场动画稳定 60fps（低端手机允许降到 30fps，但不能卡顿）
- 首屏 JS < 60KB（不含字体）
- 移动端：卷曲动画降级为简单的淡入 + 纸面上移

## 十、分阶段

| 阶段     | 内容                    | 验收标准           |
| ------ | --------------------- | -------------- |
| **P0** | 只做"卷轴展开"一个动画，一张静态纸    | 看 20 遍不腻，手机上不卡 |
| **P1** | 首页排版（竖排、界栏、鱼尾、朱印）     | 截图能直接当作品集封面    |
| **P2** | 火漆印交互 + 展开衔接 + 可选音效   | 从点击到读完首屏，节奏顺   |
| **P3** | 盆栽 + 墨点 + 选中高亮 + 夜间模式 | 每个都碰一遍，都不烦     |
| **P4** | 移动端降级 + 无障碍 + 性能优化    | 低端安卓机可用        |
| **P5** | 内容页、翻页转场、文章排版         | 能读完一篇长文不累      |

**P0 是最关键的一步。** 如果卷轴展开这个动作本身不够好看，后面全都是装修。所以我建议先只做这一个动画，做到满意为止，再往下走。

## 十一、待你决定

这五个问题定了，我就能开工：

1. **中式手卷还是西式卷轴？** （影响最大，见第六节）
2. **<u>开场要音效吗？</u>**<u> 纸的声音 + 火漆碎裂声，能极大增强仪式感，但要默认关、可开启。</u>
3. **内容是竖排还是横排？** 竖排更有味道，但长文阅读体验差、复制粘贴顺序会乱。我建议标题竖排、正文横排。
4. **盆栽放在哪？** 右下角固定（像桌面宠物）／ 首页某个角落（只在首页）／ 页脚旁边（安静）。
5. **这个站是纯展示，还是也要能发文章、收留言？** 如果只是展示，P0–P3 就够；如果要活站，还要加后台和数据库。

## 十二、参考锚点

看感觉用的，不是抄：

- **游戏**：《Journey》《Gris》《Monument Valley》—— 学它们的节奏和留白，不学画面
