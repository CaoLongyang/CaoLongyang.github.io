# 手卷 · 个人站

一个"展开"出来的个人网站。访客到达时看到的是一卷合着的手卷，点火漆、蜡碎、纸自己摊开。

**当前进度：P0（只做展开这一个动作）。** 卷内内容是占位的，正式排版另行设计。

---

## 本地预览

不需要构建、不需要依赖。两种方式任选：

```bash
# 方式一：直接打开
start site/index.html

# 方式二：起个本地服务器（推荐，避免部分浏览器的本地文件限制）
cd site && python -m http.server 5173
# 然后访问 http://localhost:5173
```

**看开场动画**：如果之前看过，点右下角「重看开场」。或者清掉 `localStorage` 里的 `scroll-opened-v1`。

**改设计从这里入手**：`css/base.css` 顶部的 `:root` 里全是变量——纸色、墨色、朱红、轴木色、手卷尺寸。改一处，全站跟着变。

## 设计规范（摘要）

| 项 | 值 |
|---|---|
| 纸 | `#f2e8d2` → `#e9dcc0` → `#dccba6`（唯一允许用渐变的地方） |
| 墨 | `#241c14`（偏褐，不用纯黑） |
| 朱 | `#a83a1c`（印章、火漆、强调，全站唯一彩色） |
| 正文 | 宋体 / 思源宋体 |
| 题跋 | 楷体 |
| 编号 | 等宽 |
| 排版 | 竖排右起，首行不缩进，列距 1.5em |
| 装饰 | 鱼尾（版心）、内框、朱印 |

**禁止**：圆角卡片、投影按钮、渐变文字、无衬线黑体正文、emoji 图标。

## 实现要点

**双语与反差。** 默认英文，右上角可切中文，选择记在 `localStorage`。排版上是刻意的错位：**英文横排贴左，中文竖排贴右**（引首），中间留白。这是东方编辑设计里最经得住看的一种对照。

文案用 `data-en` / `data-zh` 双属性挂在元素上，切换时整体替换 `textContent`，同时更新 `<html lang>`。

**焦边。** 用一个 SVG `feTurbulence` + `feDisplacementMap` 把一圈深色边框"啃"成不规则形状，内侧再加橙色内阴影当余烬。展开完成时余烬会亮一下再回落。

关键在于几何：`.char` 的 `inset` 是负的、边框很宽，这样即使被位移推得七零八落，纸的边缘也永远被盖住，不会露出细白缝。

**展开动画不用 Canvas，也不用库。**

手卷的"展开"是靠 `.view` 的宽度从 96px 变到 1080px 实现的。关键在两点：

1. **纸的宽度是固定的**（`--pw`），它在一个 `overflow:hidden` 的视口里始终居中。视口变宽，纸被"露出来"的部分变多——所以展开过程中文字不会重排，也不会抖动。
2. **卷边的阴影挂在视口两端**，而不是纸上。视口边缘正好就是纸从轴上离开的位置，所以阴影位置天然正确，不需要跟着动画走。

卷轴的重量感来自两层投影（地面投影 + 轴自身投影），纸的质感来自 SVG `feTurbulence` 生成的噪点，**零图片请求**。

**火漆裂开**是四块用 `clip-path` 切出来的碎片，各自平移旋转淡出，配一圈扩散的蜡屑环。

## 已经处理的三件事

- **二次访问不重播**：`localStorage` 记住 `scroll-opened-v1`，老访客 0 延迟直接进正文。
- **可跳过**：右下角常驻「跳过」。
- **无障碍**：`prefers-reduced-motion: reduce` 时直接跳到展开状态，不播任何动画。
